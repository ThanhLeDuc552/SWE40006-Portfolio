### Notes

* **WiX Toolset installation:** See under *"Modules/Unit Resources/Software"*.
* **Visual Studio installation:** See under *"Modules/Unit Resources/Software"*.
* **DLLs:**
* For the entry-level programmer, DLLs are a programming concept. In Microsoft Windows, these have a `.dll` extension (Dynamic-Link Library). You can create a program containing methods/functions without a `main` method, then compile it to a `.dll`. It cannot run standalone, but you can link it to other programs (ones with a `main()`) allowing them to call functions/methods from the DLL.
* Most large programs work this way (in Linux, the equivalent extension is `.so`). This allows updating parts of an application (replacing a faulty DLL to patch) without performing a full reinstall.
* Reference guide: [Creating C# Class Library DLL Using Visual Studio .NET](https://www.c-sharpcorner.com/article/creating-C-Sharp-class-library-dll-using-visual-studio-net/?utm_source=gemini)
